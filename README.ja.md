## 特許・意匠の説明資料起草

`patent-disclosure-drafting`

許可された製品根拠から技術と外観の説明を分離し、安定した図番号と専門家向け草案を作成します。

スキルディレクトリ: `.`

**実装の根拠と依存関係**

読める製品文・図と Agent。出願向けには法域・ルート、指定形式には文書ツール。出願前に特許専門家の確認が必須です。

**入力**

製品、部品、接続、動作、図面、根拠。条件付き：法域/意匠/実用新案/特許。任意：変形例・出力指定。既定 private、公開例は新規合成または許可済み匿名化審査。

**出力**

状態表紙、発明概要、技術/外観説明、図・符号表、暫定保護重点、未解決質問、専門家チェックリスト。未作成項目を明示します。

[実行手順 · 制約と停止条件 · 依頼例](references/i18n/ja.md)

> 次のスキルを使用してください： `$patent-disclosure-drafting` — 架空の可変ホルダーの部品と視図から技術・外観草案と図番号表を作り専門家へ渡します。日本語で回答し、根拠、不明点、操作権限を維持してください。

## 言語対応と検証

本書は目的、前提、入出力、手順、例、制約をまとめた日本語運用ガイドです。全参考資料の逐語訳ではありません。詳細技術資料、過去事例、スクリプトのエラー、サンプル画面、画像は原言語のままです。必要に応じて日本語で説明できます。構造・リンク・重要制約を確認していますが、各言語の母語話者による校閲は未実施です。

納品前に入力、根拠、欠損、出力ファイルと元の完了条件を照合します。未実行の工程は未検証とし、終了コードの成功を業務上の検証成功と混同しません。
