# Figure And Reference-Numeral Rules

## Numbering convention

- Use `Fig. 1`, `Fig. 2`, etc. for views.
- Use two-digit or three-digit numerals for components, reserving the hundreds digit for a subassembly when useful: `10` base frame, `20` insert, `100` upper assembly.
- Keep a numeral's meaning stable across every view and section.
- Use one source label per figure. If a figure combines sources, record the merge and review it manually.

## Minimum view checklist

For an appearance route, inspect whether the evidence supports:

- perspective/front perspective;
- front, rear, left, and right sides when silhouette matters;
- top and bottom when visible surfaces matter;
- installed or environmental view only when the environment is part of the proposed disclosure decision;
- detail views for distinctive transitions or surface patterns.

For a utility route, inspect whether the evidence supports:

- assembled view;
- exploded or sectional view for connections;
- interface/installation view;
- operating positions;
- variant or optional-part views.

## Consistency table

Before delivery, create:

Every conflict must be resolved, retained as an open question, or removed from the draft. Never silently change a numeral after it has appeared in a figure caption.

## Drawing boundary

Do not claim that a generated or redrawn figure is filing-ready. Record whether it is source evidence, an annotated review figure, or a proposed agent drawing brief.
