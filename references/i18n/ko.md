# 특허·디자인 명세 초안

`patent-disclosure-drafting` · 한국어

## 목적과 적용 범위

허가된 제품 근거로 기술·외관 설명을 분리하고 일관된 도면 번호와 전문가 전달 초안을 만듭니다.

## 구현 근거와 의존성

읽을 수 있는 제품 글·그림과 Agent가 필요합니다. 출원용은 관할·경로, 특정 형식은 문서 도구가 필요하며 출원 전 특허 전문가 검토는 필수입니다.

## 입력

제품·부품·관계·동작·도면·근거, 조건부 관할/디자인/실용신안/특허 경로. 선택 변형·출력. 기본 private이며 공개 예시는 새 합성 또는 승인된 비식별 검토가 필요합니다.

## 출력

상태 표지·발명 요약·기술/외관 설명·도면/부호표·잠정 보호 초점·미해결 질문·대리인 체크리스트. 미작성 항목은 표시합니다.

## 실행 절차

1. 관할·경로·독자 확정
2. 근거와 용어 정리
3. 외관·기술 분리
4. 부품·도면 고정 번호
5. 연결·동작·대안·근거 효과 작성
6. 뷰 일치와 과잉 정밀도 검사
7. public-synthetic은 새 허구 사례
8. 전문가 검토용 전달 확정.

## 제약과 중단 조건

신규성·소유·발명자·우선권·숨은 구조·법적 상태를 만들지 않습니다. 권리 효력·출원 보증은 없습니다. 도면 불명·사실 충돌·관할 미상은 범위를 제한하며 출원·공개는 별도 허가입니다.

## 요청 예시

다음 스킬을 사용하세요: `$patent-disclosure-drafting` — 가상의 조절식 홀더 부품 설명·뷰로 기술/외관 초안과 번호표를 만들어 전문가에게 전달합니다. 한국어로 답하고 근거, 미확인 사항과 작업 권한을 유지하세요.

## 전체 명세

[스킬 진입점과 상세 자료](../../SKILL.md).

사용자가 명시한 출력 언어를 따르고, 지정이 없으면 요청 언어를 따릅니다. 명령, 스킬 ID, JSON 키, 열거값, 단위와 원문 인용은 유지합니다. 번역과 원문을 구분하고 언어로 국가, 통화, 관할을 추정하지 않습니다. 전체 명세의 관련 자료를 읽고 기존 검증과 권한 조건을 적용합니다.

전달 전에 입력, 근거, 결측값, 출력 파일과 원래 완료 기준을 대조합니다. 실행하지 않은 단계는 미검증으로 표시하며 스크립트의 정상 종료를 업무 검증 성공으로 취급하지 않습니다.

## 언어 지원과 검증

이 문서는 목적, 전제, 입출력, 절차, 예시와 제약을 다루는 한국어 운영 가이드이며 모든 참고 문서의 문장별 번역은 아닙니다. 상세 기술 자료, 과거 사례, 스크립트 오류, 예제 화면과 이미지는 원래 언어를 유지합니다. 요청 시 해당 언어로 설명할 수 있습니다. 구조, 링크와 핵심 제약을 확인했으나 각 언어 원어민 교정은 수행하지 않았습니다.
