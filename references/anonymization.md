# Public Synthetic Case And Anonymization

## Public-release rule

For a public case, use a new fictional product and new wording. Do not merely replace a brand name in the original case. The public example must not allow a reader to reconstruct the source project from:

- product name, model, SKU, ASIN, patent number, filing date, or file name;
- exact dimensions, unique geometry, material stack, supplier, customer, company, person, or location;
- original CAD, PPT, drawings, photographs, screenshots, or extracted metadata;
- distinctive claim strategy, unpublished search result, complaint details, or private commercial terms.

## Replacement method

1. Retain the workflow goal, not the product identity.
2. Replace the object with a nearby but different category.
3. Change the component names, geometry, materials, and dimensions.
4. Use illustrative values only when marked synthetic.
5. Rewrite all prose from the method, not by paraphrasing private source text.
6. Run a literal scan for names, paths, extensions, identifiers, and unusual phrases.
7. Run a human comparison for source fingerprints and strategy leakage.

## Public audit record

State:

```text
source case used: method-only reference
original files copied: no
original images copied: no
real names/identifiers retained: no
synthetic product: yes
legal conclusion: none
review boundary: patent agent/attorney required
```

## Safe public wording

Prefer “synthetic example”, “illustrative component”, “draft for agent review”, and “unknown pending confirmation”. Avoid “will be granted”, “guaranteed non-infringing”, “final claim”, or “ready to file”.
